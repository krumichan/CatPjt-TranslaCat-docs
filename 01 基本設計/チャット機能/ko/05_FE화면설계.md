# 채팅 기능 FE 화면 설계

## 1. 목적

Phase 1 기본 채팅과 Phase 1.5 친구 기반 소셜 채팅의 사용자 흐름, Route, 상태 표시, API 연동 기준을 정의한다.

## 2. 화면 목록

| 화면/기능 | Route | 설명 |
|---|---|---|
| 채팅방 목록 | `/chat` | MANUAL/FRIEND 방 목록 |
| 채팅방 상세 | `/chat/rooms/{roomId}` | 메시지/번역/언어 설정 |
| 친구 목록 | `/friends` | 친구 목록, DIRECT, 그룹 선택 |
| 사용자 검색 | `/friends/search` | publicId 검색/친구 요청 |
| 그룹 생성 | `/friends/group/new` | 선택 친구 기반 그룹 생성 |
| 프로필 설정 | `/settings/profile` | 내 프로필 조회/수정 |
| 친구 요청 알림 센터 | `/friends` 내 Modal | 받은/보낸 요청 처리 |
| 차단 관리 | 친구 화면 관련 UI | 차단/목록/해제 |

## 3. 전체 흐름

친구 추가:

```text
/friends
  ↓ 사용자 검색
/friends/search
  ↓ publicId 검색
검색 결과
  ↓ 친구 요청
PENDING
  ↓ 상대 알림 센터
수락
  ↓
친구 목록 반영
```

FRIEND DIRECT:

```text
/friends
  ↓ 친구 카드 1:1 채팅
POST /chat/friends/{friendUserId}/direct-room
  ↓
/chat/rooms/{roomId}
```

FRIEND GROUP:

```text
/friends
  ↓ 그룹 선택
친구 복수 선택
  ↓ 그룹 만들기
/friends/group/new
  ↓ 그룹명/설명
POST /chat/friends/group-rooms
  ↓
/chat/rooms/{roomId}
```

## 4. 프로필 화면

Route: `/settings/profile`

표시:
- publicId
- nickname
- profileImageUrl
- bio

액션:
- 조회
- 수정
- 저장
- 실패 시 Retry

상태:
- Loading
- 조회 성공
- 수정 중
- 저장 성공
- validation
- API Error
- Retry

## 5. 사용자 검색

Route: `/friends/search`

구성:
- publicId 입력
- 검색 버튼
- 결과 카드
- 친구 요청 버튼
- 관계 상태

validation:
- 빈 publicId 검색 차단

상태:
- 초기
- Loading
- 성공
- 사용자 없음
- 이미 친구
- 요청 완료
- 요청 실패

## 6. 친구 요청 알림 센터

`/friends` 알림 버튼에서 Dialog/Modal로 제공한다.

기능:
- 받은 요청
- 보낸 요청
- 수락
- 거절
- 취소

수락 흐름:
1. 수락 클릭
2. API 완료
3. 요청 항목 제거
4. 친구 목록 refetch

실제 결합 테스트에서는 요청 항목이 사라진 것을 확인한 뒤 상대 사용자 친구 목록을 재조회한다.

## 7. 친구 목록

Route: `/friends`

친구 카드:
- nickname 또는 현재 제공 가능한 표시 정보
- publicId
- profile image
- 1:1 채팅
- 친구 메뉴: 삭제/차단

상단 액션:
- 사용자 검색
- 알림 센터
- 그룹 선택

상태:
- Loading
- 목록
- 검색 필터
- Empty
- Error/Retry

## 8. 그룹 선택 모드

`/friends` 내부에서 동작한다.

- 선택 모드 시작
- 친구 카드 선택/해제
- 선택 수 표시
- `그룹 만들기 (N)` CTA
- 차단 사용자는 목록 제외

FE 필터와 별개로 BE에서 친구/차단 관계를 재검증한다.

## 9. FRIEND GROUP 생성

Route: `/friends/group/new`

입력:
- 선택 친구 표시
- 그룹명
- 설명
- 그룹 채팅 만들기

validation:
- 그룹명 필수
- 선택 멤버 유효성
- 비친구 멤버 제거/차단
- API 실패 시 오류 + Retry

성공:

```text
POST /api/v1/chat/friends/group-rooms
  ↓ room.id
/chat/rooms/{roomId}
```

## 10. 채팅방 목록

Route: `/chat`

표시:
- MANUAL DIRECT
- MANUAL GROUP
- FRIEND DIRECT
- FRIEND GROUP

전환 정책:
- 일반 사용자용 userId 직접 입력 방 생성 UI 비노출
- `친구와 채팅 시작` CTA는 `/friends` 이동
- 기존 MANUAL 방 계속 접근 가능

## 11. 채팅방 상세

Route: `/chat/rooms/{roomId}`

기능:
- 방 정보
- 초기 메시지
- cursor 과거 메시지 로드
- ID 기준 중복 제거
- 메시지 전송
- WebSocket 수신
- WebSocket 미연결 시 REST fallback
- 번역 상태
- translation.completed 반영
- 방 언어 설정 조회/저장

상태:
- 메시지 Empty
- PENDING
- COMPLETED
- FAILED + 원문 유지
- 전송 실패
- 언어 저장 실패

## 12. Loading / Empty / Error

Loading:
- 프로필
- 검색
- 친구 목록
- 요청 목록
- 차단 목록
- 방 목록/상세
- 메시지 추가 로드
- 그룹 생성/메시지 전송

Empty:
- 검색 결과 없음
- 친구 없음
- 받은/보낸 요청 없음
- 차단 사용자 없음
- 채팅방 없음
- 메시지 없음

Error:
- 오류 메시지
- 가능한 경우 Retry
- 사용자 입력 및 원문 유지

## 13. 반응형/다크모드

주요 화면을 PC/모바일 및 다크모드 기준으로 간단 확인하였다.

주의:
- 긴 publicId overflow
- 긴 nickname
- 친구 카드 액션
- Modal 내부 스크롤
- 그룹 선택 카드
- 그룹 생성 폼
- 모바일 고정 폭 모달 방지
- 다크모드 텍스트 대비

## 14. i18n

주요 Social/Chat 화면은 `ko`, `ja` locale을 지원한다. E2E에서 두 locale 주요 화면의 번역 key 오류 여부를 확인한다.

## 15. 후속 UI

- 프로필/배경 이미지 파일 업로드
- FRIEND DIRECT 상대 nickname/profile 표시 강화
- 개인 기본 언어 + 방별 override
- 번역 재시도 UI
