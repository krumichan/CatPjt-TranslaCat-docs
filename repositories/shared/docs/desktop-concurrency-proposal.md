상태: **검토용 설계, 실행기에 미적용**. 2026-10-23 `RPG 게임 만들기` 채팅의 human 메시지 `01a168bc-b092-7601-b687-d3e8770ab071`에서 실제 자원을 확인한 제한 병행과 관련 채팅 안내를 요청했다. 다음 구현 변경은 자동 승인 검토가 공용 API·동작 변경의 범위를 이유로 거부해 추가 승인 대기 상태다. 현재 배포된 실행기와 원격 잠금은 그대로다.

状態：**審査用の設計、実行器には未適用**。2026-10-23、`RPG 게임 만들기`チャットのhumanメッセージ`01a168bc-b092-7601-b687-d3e8770ab071`で、実際のリソースを確認した限定並行実行と関連チャットへの案内が依頼された。以下の実装変更は、共通API・動作変更の範囲を理由に自動承認審査で拒否され、追加承認待ち。現在配備されている実行器とリモートロックはそのままとしている。

Build는 `NoGameplay`를 명시해야 한다. 이 프로필에서 게임·Editor UI·GPU 에셋 작업·실제 DB/API 서비스 시작·브라우저/PC 화면 조작을 실행하지 않는다. 게임 프로세스를 띄우는 검사는 Build로 분류하지 않는다. 무인 엔진 컴파일도 실제 클라이언트·Editor UI를 시작하지 않는지 어댑터를 확인한다.

Buildでは`NoGameplay`を明示しなければならない。このプロファイルではゲーム・Editor UI・GPUアセット作業・実際のDB/APIサービス開始・ブラウザー/PC画面操作を実行しない。ゲームプロセスを起動する検査はBuildに分類しない。無人のエンジンコンパイルでも、実際のクライアント・Editor UIを開始しないかアダプターを確認する。

시작 전 CPU 표본과 이미 예약한 CPU의 합계에 각각 10% 이상의 여유를 둔다. RAM은 새 예약과 기존 작업의 미사용 예약분을 고려한 뒤 물리 메모리 2GiB, commit 1GiB 이상의 여유를 유지하며, 전체 예약도 시스템용 3GiB를 남긴다. 예상 디스크 증가 예약을 제외한 여유 공간은 5GiB 이상이어야 한다. 이 값은 자원 측정과 실제 빌드의 peak 결과를 확인해 조정할 제안이다. GPU 사용률/VRAM은 관측하지만 Windows 전체 GPU/디스크 IO의 강제 상한 기능을 구현한 것으로 표시하지 않는다.

開始前のCPU標本と予約済みCPUの合計について、それぞれ10%以上の余裕を確保する。RAMは新しい予約と既存作業の未使用予約分を考慮したうえで、物理メモリ2GiB、commit 1GiB以上の余裕を維持し、予約全体でもシステム用に3GiBを残す。予想ディスク増加の予約を除いた空き容量は5GiB以上必要。これらは、リソース測定と実際のビルドのpeak結果を確認して調整するための提案値。GPU使用率/VRAMは観測するが、Windows全体のGPU/ディスクIOに対する強制上限機能を実装したとは表示しない。

## 구현 범위와 보존 조건 / 実装範囲と保全条件

1. 공용 잠금 모듈에 명시적으로 선택하는 Build/Gameplay 예약을 추가하고, 기존 인자와 기본 Exclusive 동작은 유지한다. 상태 조회에는 각각의 작업 ID·프로필·예약을 표시한다.

   共通ロックモジュールに、明示的に選択するBuild/Gameplay予約を追加し、既存の引数と既定のExclusive動作を維持する。状態照会では、各作業ID・プロファイル・予約を表示する。
2. 정상 신규 작업에서만 공유 호환 게이트와 별도 Gameplay 게이트를 잡는다. 이미 실행 중인 이전 버전 작업의 배타적 파일 핸들은 그대로 유지하며, 그 작업이 끝날 때까지 새 공유 진입도 거부한다. 잠금 파일 삭제나 소유권 탈취를 하지 않는다.

   正常な新規作業だけで、共有互換ゲートと別のGameplayゲートを取得する。実行中の旧バージョン作業の排他的ファイルハンドルはそのまま保持し、その作業が終わるまで新しい共有進入も拒否する。ロックファイルの削除や所有権の奪取は行わない。
3. CPU/메모리 제한은 **새로 시작하는 전용 worker와 그 자식**에만 Windows Job Object로 적용한다. 기존 데스크톱 프로세스·다른 작업·전역 환경에는 적용하지 않는다. 제한을 설정할 수 없으면 작업을 시작하지 않는다. 메모리 상한은 물리 RAM 점유율이 아닌 전용 commit 제한이며, 초과한 작업은 할당 실패로 실패할 수 있다.

   CPU/メモリ制限は、**新しく開始する専用workerとその子**だけにWindows Job Objectで適用する。既存デスクトッププロセス・他作業・グローバル環境には適用しない。制限を設定できなければ作業を開始しない。メモリ上限は物理RAM使用率ではなく専用commitの制限であり、超過した作業は割り当て失敗によって失敗する可能性がある。
4. **자동 프로세스 종료 기능은 넣지 않는다.** `TerminateProcess`, `TerminateJobObject`, 종료 시 자식 자동 제거 옵션을 사용하지 않는다. 하위 작업이 남아 있으면 예약과 대기를 유지하고 상태를 보고한다. 컴파일 서버/daemon 재사용을 끄는 어댑터 옵션을 사용한다.

   **プロセスの自動終了機能は追加しない。** `TerminateProcess`、`TerminateJobObject`、終了時の子の自動削除オプションは使わない。下位作業が残っている場合は予約と待機を維持して状態を報告する。コンパイルサーバー/daemonの再利用を無効にするアダプターオプションを使う。
5. 결과에 사용 프로필·예산·시작 전 자원·실제 종료 코드·메모리 peak를 기록하고 기존 소스 해시 검증·JobId·결과 회수·SSH 인증을 유지한다. 자원 부족은 미시작 상태로 반환하고 자동 재시작·노트북 fallback을 하지 않는다.

   使用したプロファイル・予算・開始前のリソース・実際の終了コード・メモリpeakを結果に記録し、既存のソースハッシュ検証・JobId・結果回収・SSH認証を維持する。リソース不足は未開始状態として返し、自動再起動・ノートPCへのfallbackは行わない。
6. 기존 FE 실행기도 명시적인 Build 프로필을 호출하도록 연결한 뒤 검증한다. Unity/Unreal의 대화형 브리지나 외부 서비스는 일반 자식 상속만으로 제한된다고 가정하지 않는다. 해당 어댑터가 신규 전용 실행 주체와 완료 상태를 보장하기 전에는 Exclusive를 유지한다.

   既存FE実行器も、明示的なBuildプロファイルを呼ぶように接続してから検証する。Unity/Unrealの対話型ブリッジや外部サービスが、通常の子プロセス継承だけで制限されるとは仮定しない。該当アダプターが新規専用実行主体と完了状態を保証するまではExclusiveを維持する。

## 필요한 검증 / 必要な検証

- 두 Build의 실제 중첩, 세 번째 예약 차단, Gameplay 두 개 중첩 차단, 자원이 충분한 Build+Gameplay 중첩.

  二つのBuildの実際の重複、三つ目の予約の遮断、二つのGameplayの重複遮断、リソースが十分な場合のBuild+Gameplayの重複。
- CPU/RAM/commit/디스크 부족 시 task 미시작, 잘못된 token의 해제 차단, 정상·실패 종료 후 소유 예약 해제.

  CPU/RAM/commit/ディスク不足時にtaskを開始しないこと、不正なtokenによる解放の遮断、正常・失敗終了後の所有予約の解放。
- 이전 버전 배타적 핸들과의 상호 배제, 실행 중인 이전 작업 보존, worker가 사라져도 살아 있는 관리 자식의 예약 유지.

  旧バージョンの排他的ハンドルとの相互排除、実行中の旧作業の保全、workerが消えても生存中の管理対象の子の予約を維持すること。
- 새 작업의 CPU/메모리 상한, 종료 코드·UTF-8 로그·결과 회수 보존. 원본·개인 설정·DB·전역 환경 변경 없음.

  新規作業のCPU/メモリ上限、終了コード・UTF-8ログ・結果回収の保全。原本・個人設定・DB・グローバル環境は変更しない。

검증된 것으로 표시하지 않는다. 현재 `DesktopResourceCaps.cs` 초안은 임시 검토 폴더에만 보존하며, 공용 모듈에 import하거나 데스크톱의 운영 worker에 연결하지 않았다. 실제 게임 플레이나 제품 전체 빌드를 새로 수행한 결과도 아니다.

検証済みとは表示しない。現在の`DesktopResourceCaps.cs`草案は一時審査フォルダーだけに保全し、共通モジュールへのimportやデスクトップの運用workerへの接続はしていない。実際のゲームプレイや製品全体のビルドを新たに実施した結果でもない。
