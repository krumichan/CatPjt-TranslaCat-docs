## 사용 흐름 / 利用の流れ

참여 중인 오픈채팅방의 우측 메뉴에서 **내 방별 프로필 · 사진**을 연다. 사진을 선택해 미리 본 뒤 저장하거나 선택을 취소할 수 있다. 기존 사진은 확인 창에서 삭제하면 기본 아이콘으로 바뀐다. 일반 계정 사진이나 다른 방의 사진을 바꾸지 않는다.

参加中のオープンチャットの右側メニューから **自分のルーム別プロフィール・写真** を開きます。写真を選んでプレビューを確認してから保存するか、選択を取り消せます。既存の写真は確認ダイアログで削除すると既定アイコンへ戻ります。通常アカウントや他のルームの写真は変更しません。

지원 파일은 JPG·PNG·WEBP, 최대 5MiB다. OS 이미지 선택기를 사용하며 카메라·마이크 권한을 추가하지 않는다. 원래 파일명·앨범 정보·EXIF를 별도 요청 필드로 전송하지 않는다. 선택한 파일의 로컬 사본을 고정 이름 `profile.jpg`·`profile.png`·`profile.webp`로 전송한다.

対応ファイルは JPG・PNG・WEBP、最大 5MiB です。OS の画像選択機能を使い、カメラ・マイク権限は追加しません。元のファイル名・アルバム情報・EXIF を別のリクエストフィールドとして送信しません。選択ファイルのローカルコピーを固定名 `profile.jpg`・`profile.png`・`profile.webp` で送信します。

방을 생성하거나 참여한 뒤 사진을 설정한다. 사진 저장 실패를 이유로 방 생성·참여 요청을 반복하지 않는다. 오픈채팅 탐색·생성 화면의 과거 ‘프로필 이미지·관리 기능 준비 중’ 안내도 현재 기능과 메뉴 위치를 설명하도록 수정했다.

ルームの作成・参加後に写真を設定します。写真保存の失敗を理由にルーム作成・参加リクエストを繰り返しません。オープンチャットの検索・作成画面にあった「プロフィール画像・管理機能は準備中」という案内も、現在の機能とメニュー位置の説明へ変更しました。

## 기존 서버 계약 / 既存サーバー契約

| 요청 / リクエスト | 용도 / 用途 |
| --- | --- |
| `GET /chat/rooms/{roomId}` 및 OPEN 상세 조회 | 현재 방·참여·종료 상태 확인 / 現在のルーム・参加・終了状態を確認 |
| `GET /chat/open-rooms/{roomId}/me/profile` | 내 방별 프로필 확인 / 自分のルーム別プロフィールを確認 |
| `POST /chat/open-rooms/{roomId}/me/profile-image` | multipart `file` 업로드 / multipart の `file` をアップロード |
| `DELETE /chat/open-rooms/{roomId}/me/profile-image` | 내 방별 사진 삭제 / 自分のルーム別写真を削除 |

API client의 기존 인증·세션·취소·오류 경계를 유지하고 multipart에 JSON Content-Type을 강제하지 않는다. 기존 BE·CHAT API를 사용하며 이 기능만을 위한 서버 코드·DB 변경은 없다.

API client の既存の認証・セッション・キャンセル・エラー境界を維持し、multipart に JSON Content-Type を強制しません。既存 BE・CHAT API を使用し、この機能だけのためのサーバーコード・DB 変更はありません。

저장·삭제 직전에 방 참여 상태와 방별 멤버 ID를 다시 확인한다. 삭제 확인 창을 열었을 때의 사진과 서버의 현재 사진이 다르면 삭제하지 않는다. 로그아웃·계정 전환·화면 이탈 뒤의 지연 응답은 새 화면에 반영하지 않는다.

保存・削除の直前に参加状態とルーム別メンバー ID を再確認します。削除確認ダイアログを開いた時点の写真とサーバーの現在の写真が異なる場合は削除しません。ログアウト・アカウント切替・画面離脱後の遅延応答は新しい画面へ反映しません。

서버에 변경을 보낸 뒤 연결이 끊기거나 응답이 유실되면 자동 재전송하지 않는다. 현재 프로필을 다시 불러오고 사용자가 결과를 확인한 뒤 새 작업을 허용한다. OS 사진 선택기 동안 앱이 비활성화되는 경우에는 같은 계정의 로컬 선택 초안을 보존한다.

変更をサーバーへ送信した後に接続が切れたり応答を失ったりした場合、自動再送はしません。現在のプロフィールを再取得し、ユーザーが結果を確認した後で新しい操作を許可します。OS の写真選択中にアプリが非アクティブになる場合は、同じアカウントのローカル選択内容を保持します。

사진 URL은 HTTPS만 표시하며 잘못된 URL·이미지 읽기 실패에는 기본 아이콘을 표시한다. 오픈채팅 참여자 목록과 사용자 메시지의 방별 프로필을 표시한다. 숨겨진 메시지·탈퇴 작성자·SYSTEM 메시지에서는 사진을 표시하지 않는다.

写真 URL は HTTPS のみ表示し、不正 URL や画像の読み込み失敗時には既定アイコンを表示します。オープンチャット参加者一覧とユーザーメッセージにルーム別プロフィールを表示します。非表示メッセージ・退会した投稿者・SYSTEM メッセージでは写真を表示しません。
