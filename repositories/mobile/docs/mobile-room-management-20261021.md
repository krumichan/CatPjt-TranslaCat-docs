## 설정에서 나의 ID 확인과 복사

## 設定で自分の ID を確認・コピー

설정의 **나의 TranslaCat ID** 카드에서 값을 확인한다. **TranslaCat ID 복사**는 그 ID만 클립보드에 쓰고, **ID 공유**는 사용자가 눌렀을 때만 운영체제 공유 창을 연다. ID를 길게 눌러 직접 선택·복사할 수도 있다. 클립보드의 기존 내용을 읽거나 자동으로 공유하지 않는다.

設定の **나의 TranslaCat ID（自分の TranslaCat ID）** カードで値を確認する。**TranslaCat ID 복사（TranslaCat ID をコピー）** はその ID だけをクリップボードへ書き込み、**ID 공유（ID を共有）** はユーザーが押したときだけ OS の共有シートを開く。ID を長押しして直接選択・コピーすることもできる。クリップボードの既存内容を読んだり、自動的に共有したりしない。

원본은 기존 로그인·복원 과정의 `GET /api/v1/users/me/profile`로 검증한 `auth.user.publicId`다. 웹 설정과 `GET /api/v1/users/search?publicId=...` 친구 검색도 같은 필드를 사용한다. 현재 발급기의 `TC-XXXX-XXXX` 형식만 강제하지 않고 기존 ID의 대소문자·형식을 그대로 유지한다. 일반 숫자 DB ID나 OPEN의 `memberCode`와 구분한다.

原本は既存のログイン・復元処理の `GET /api/v1/users/me/profile` で検証した `auth.user.publicId` である。Web の設定と `GET /api/v1/users/search?publicId=...` の友達検索も同じフィールドを使う。現在の発行機の `TC-XXXX-XXXX` 形式だけを強制せず、既存 ID の大文字・小文字と形式をそのまま保つ。一般の数値 DB ID や OPEN の `memberCode` とは区別する。

로그인 복원 중에는 확인 중 안내를, 로그아웃·만료 상태에는 로그인 안내를 표시한다. ID가 없거나 공백·제어문자 등 잘못된 값이면 복사·공유 버튼 대신 계정 정보 재확인을 제공한다. 새 프로필 조회 경로를 중복 구현하지 않고 기존 인증 복원 경로를 재사용한다. 복사 실패는 길게 눌러 복사하는 방법을 안내하며 OS 오류 원문은 표시하지 않는다.

ログイン復元中は確認中の案内、ログアウト・期限切れ時はログイン案内を表示する。ID がない場合や空白・制御文字などの不正な値なら、コピー・共有ボタンの代わりにアカウント情報の再確認を提供する。新しいプロフィール取得経路を重複実装せず、既存の認証復元経路を再利用する。コピー失敗時は長押しでコピーする方法を案内し、OS エラーの原文は表示しない。

화면 활동이나 계정이 바뀌면 이전 성공·실패 안내를 무효화한다. 이미 시작한 OS 작업의 잠금은 실제 Promise가 끝나야 해제하므로 복귀·계정 전환 중에 복사·공유를 겹쳐 시작하지 않는다. 이미 사용자가 시작한 OS 복사·공유의 취소·회수나 실제 상대방 수신은 보장하지 않는다.

画面のアクティブ状態やアカウントが変われば、以前の成功・失敗案内を無効にする。開始済み OS 操作のロックは実際の Promise が終わるまで解除しないため、復帰・アカウント切り替え中にコピー・共有を重ねて開始しない。ユーザーが開始済みの OS コピー・共有の取り消し・回収や、相手による実際の受信は保証しない。

## 방 관리의 역할과 신원

## ルーム管理の役割と身元

GROUP 초대는 현재 활성 방에서 방장·관리자에게 제공한다. 이미 참여 중인 친구를 제외하고 선택된 친구와 입력한 공개 ID를 대조한다. 참여자 목록은 방의 기존 공개 계약을 사용한다.

GROUP 招待は現在アクティブなルームのオーナー・管理者へ提供する。参加済みの友達を除外し、選択した友達と入力した公開 ID を照合する。参加者一覧はルームの既存公開契約を使う。

OPEN은 일반 참여자·관리자의 퇴실과 방장의 방 종료를 구분한다. 방장만 위임·관리자 지정/해제를 할 수 있고, 관리자는 일반 참여자에 대한 강퇴 권한 범위에서 동작한다. 종료된 방의 일반 참여자는 퇴실할 수 있으나 새 초대·역할 변경과 구분한다. 클라이언트의 표시 여부와 별개로 서버가 각 요청 권한을 다시 판단한다.

OPEN では一般参加者・管理者の退室と、オーナーによるルーム終了を区別する。委任・管理者指定と解除はオーナーだけができ、管理者は一般参加者に対する強制退室の権限範囲で操作する。終了済みルームの一般参加者は退室できるが、新しい招待・役割変更とは区別する。クライアント上の表示可否とは別に、サーバーが各要求の権限を再判断する。

OPEN 참여자에는 방별 닉네임·멤버 코드·역할을 사용하고 일반 프로필의 TranslaCat ID·이메일을 복사하지 않는다. 변경 결과를 알 수 없는 응답에서는 동일 변경을 자동으로 다시 보내지 않고 최신 방 상태를 확인한다.

OPEN 参加者にはルーム別ニックネーム・メンバーコード・役割を使い、一般プロフィールの TranslaCat ID・メールアドレスをコピーしない。変更結果が不明な応答では、同じ変更を自動再送せず、最新のルーム状態を確認する。

관리 화면의 실시간 이벤트 즉시 반영은 아직 구현하지 않았다. 현재 상태 갱신은 진입·foreground 복귀·수동 조회·변경 전 preflight로 제한한다. 웹에서 바뀐 역할·강퇴·종료가 즉시 화면에 반영되는 조건이나 재참여 후 cache 전체 수락을 완료로 표시하지 않는다.

管理画面へのリアルタイムイベントの即時反映はまだ実装していない。現在の状態更新は、入場・foreground 復帰・手動取得・変更前の preflight に限定する。Web で変わった役割・強制退室・終了が直ちに画面へ反映される条件や、再参加後の cache 全体の受け入れを完了とは表示しない。
