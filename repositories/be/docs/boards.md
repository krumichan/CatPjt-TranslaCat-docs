# 게시판

웹의 `/boards`에서 로그인한 회원이 일반·익명 게시판을 사용한다. 현재 ADMIN 권한을 가진 계정은 관리자 전용 게시판에도 접근할 수 있다. 익명 게시판 응답에는 작성자 이름과 사용자 ID를 포함하지 않는다. API 접근에는 기존 Bearer 인증을 사용한다.

## 글, 댓글과 잠금

게시글의 제목과 본문 및 댓글·답글은 일반 텍스트다. 게시글·댓글 작성자는 각 항목에 열람 비밀번호를 지정할 수 있다. 비밀번호는 유니코드 8자 이상, UTF-8 72바이트 이하이고 기존 BCrypt 인코더로 해시한다. 작성자와 관리자도 열람 시 비밀번호가 필요하다. 성공하면 현재 로그인 세션에 30분간 권한을 부여한다. 변경과 삭제는 작성자만 할 수 있고, 비밀 항목을 수정하면 그 항목의 번역과 잠금 해제가 초기화된다.

댓글·답글은 최대 8단계까지 작성할 수 있다. 비밀글은 목록에서 제목과 작성자를 감추며, 댓글과 첨부도 본문을 열어야 접근할 수 있다. 비밀 댓글의 자식 목록과 답글 작성은 모든 상위 항목의 잠금 해제를 요구한다. 비밀 답글도 자체 비밀번호를 확인한다. 보호된 내용과 서명 URL은 API 로그 및 HTTP 캐시에서 제외한다.

## R2

운영 BE의 `CLOUDFLARE_R2_BOARD_BUCKET`에 게시판 전용 비공개 버킷 이름을 지정한다. 기존 R2 API 자격증명에서 해당 버킷의 업로드와 삭제 권한을 부여한다. 버킷의 공개 URL과 공개 도메인은 사용하지 않는다. R2 CORS에는 트랜슬라켓 웹 원점의 `PUT`을 허용한다. 완료에 쓰는 ETag는 BE가 R2 ListParts에서 읽는다.

일반·익명 게시판은 파일당 30,000,000바이트까지 허용한다. 관리자 전용 게시판은 R2의 5TiB에서 5GiB를 뺀 객체 한도까지 허용한다. 게시글당 최대 20개를 첨부할 수 있다. 브라우저는 유효기간이 있는 파트 URL을 받아 R2로 직접 전송하며, 실패 후 작성 화면에서 저장을 재시도하면 이미 수신한 파트를 건너뛴다. BE가 파트 크기와 완료된 객체의 크기를 검증한 후 게시글에 연결한다. 다운로드 URL은 60초 동안 유효하다. 미완료 업로드는 6일간 재개할 수 있다. 글에서 분리된 파일과 만료된 객체는 백엔드에서 정리한다.

## 번역 및 적용 순서

한국어·일본어·영어 UI 설정으로 자동 번역하며, 학습 모드에는 한국어를 쓴다. 잠금을 해제한 사용자가 비밀 콘텐츠를 조회한 뒤에만 해당 항목을 번역 대기열에 추가한다. 작성 화면에 해당 조건을 표시한다. 대기하거나 번역에 실패한 동안 원문을 읽을 수 있다. 번역 결과는 항목 버전과 언어별로 저장한다.

1. 비공개 R2 버킷과 CORS를 준비하고 BE 배포 환경에 버킷을 연결한다.
2. BE의 `scripts/sql/20261114_boards.sql`을 대상 DB에 적용한다.
3. `BOARD_ko`, `BOARD_ja`, `BOARD_en` 번역 규칙이 담긴 AI 버전을 먼저 배포하고 BE와 FE를 배포한다.
4. 별도 관리자와 일반 회원 계정을 사용해 잠금, 작성자 표시, 비밀 답글, 30MB 경계, 분할 업로드 재개와 다운로드, 3개 언어 번역을 검증한다.
