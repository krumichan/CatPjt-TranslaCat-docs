## 3. Phase 1.5 완료 범위

### 사용자 프로필
- 내 프로필 조회/수정
- nickname, profileImageUrl, bio
- TranslaCat 전용 publicId 표시
- 조회 실패/재시도 UI

현재 프로필 이미지는 URL 기반이다. TranslaCat 관리형 파일 업로드는 별도 후속 이슈에서 처리한다.

### publicId 검색
- publicId 정확 검색
- 검색 결과 및 관계 상태 표시
- 자기 자신/이미 친구/PENDING/차단 관계 액션 제한
- 사용자 없음 Empty 상태

### 친구 요청
- 전송
- 받은 요청/보낸 요청 조회
- 수락/거절/취소
- 중복 요청 방지
- 이미 친구인 사용자 요청 제한
- 차단 관계 요청 제한

### 친구 목록
- 목록 조회
- 검색 필터
- Empty 상태
- 친구 삭제
- FRIEND DIRECT 시작
- 그룹 선택 모드

### 차단
- 차단/목록/해제
- 차단 시 친구 목록 제외
- 그룹 선택 대상 제외
- 친구 요청 및 FRIEND 채팅 시작 제한

### FRIEND DIRECT
- 친구 목록에서 1:1 채팅 시작
- `roomType = DIRECT`
- `sourceType = FRIEND`
- 동일 사용자 조합의 기존 FRIEND DIRECT 재사용
- MANUAL DIRECT는 FRIEND DIRECT로 재사용하지 않음

### FRIEND GROUP
- 친구 복수 선택
- 그룹명/설명 입력
- `roomType = GROUP`
- `sourceType = FRIEND`
- 생성자 OWNER, 선택 친구 MEMBER
- 비친구/차단 사용자 검증
- Phase 1.5에서는 동일 멤버 조합의 그룹 중복 생성 허용

## 4. FE 주요 Route

| 기능 | Route |
|---|---|
| 채팅방 목록 | `/chat` |
| 채팅방 상세 | `/chat/rooms/{roomId}` |
| 친구 목록 | `/friends` |
| 사용자 검색 | `/friends/search` |
| 친구 그룹 생성 | `/friends/group/new` |
| 프로필 설정 | `/settings/profile` |

친구 요청은 `/friends`의 알림 센터 Modal에서 처리한다.

## 5. Phase 1 → 1.5 전환 정책

```text
/chat
  ↓ 친구와 채팅 시작
/friends
  ├─ 친구 카드 → FRIEND DIRECT
  └─ 그룹 선택 → /friends/group/new → FRIEND GROUP
```

- 기존 `POST /api/v1/chat/rooms` 유지
- 기존 MANUAL 방 계속 사용 가능
- 일반 사용자 UI에서는 내부 userId 직접 입력 방 생성 UI 비노출
- 정상 사용자 진입점은 publicId 검색과 친구 목록
