- 一覧取得

### ブロック
- ブロック/一覧/解除
- ブロック時に友達一覧から除外
- グループ選択対象から除外
- 友達リクエストおよびFRIENDチャット開始制限

### FRIEND DIRECT
- 友達一覧から1:1チャット開始
- `roomType = DIRECT`
- `sourceType = FRIEND`
- 同一ユーザー組み合わせの既存FRIEND DIRECTを再利用
- MANUAL DIRECTはFRIEND DIRECTとして再利用しない

### FRIEND GROUP
- 友達複数選択
- グループ名/説明入力
- `roomType = GROUP`
- `sourceType = FRIEND`
- 作成者OWNER、選択友達MEMBER
- 非友達/ブロックユーザー検証
- Phase 1.5では同一メンバー構成のグループ重複作成を許可

## 4. FE主要Route

| 機能 | Route |
|---|---|
| チャットルーム一覧 | `/chat` |
| チャットルーム詳細 | `/chat/rooms/{roomId}` |
| 友達一覧 | `/friends` |
| ユーザー検索 | `/friends/search` |
| 友達グループ作成 | `/friends/group/new` |
| プロフィール設定 | `/settings/profile` |

友達リクエストは `/friends` の通知センターModalで処理する。

## 5. Phase 1 → 1.5 移行方針

```text
/chat
  ↓ 友達とチャット開始
/friends
  ├─ 友達カード → FRIEND DIRECT
  └─ グループ選択 → /friends/group/new → FRIEND GROUP
```

- 既存 `POST /api/v1/chat/rooms` を維持
- 既存MANUALルームは継続利用可能
- 一般ユーザーUIでは内部userId直接入力ルーム作成UIを公開しない
- 通常入口はpublicId検索と友達一覧
